# 运动分析版CSV契约

## 基本原则

复制第一阶段基础CSV，生成文件名带 `_运动分析` 的第二版CSV。不要覆盖基础版，不要删除、重命名或重排已有列，不要另行拆分CSV。

人工复核固定列保持为：

```text
帧序号
PTS时间_s
相邻PTS差_s
OSD时间
OSD秒间帧序号
修正后OSD秒间帧序号
帧类型
运动异常备注
```

`OSD时间`沿用第一阶段的八位 `hh:mm:ss` 格式并保留前导零，第二阶段不得改写其格式。

分析主要填写：

```text
修正后OSD秒间帧序号
运动异常备注
推定帧间隔增量
运动不连续倍率
采用目标
有效特征点数
正反向误差_px
备注
```

## 到达帧归属

每一行描述到达该帧的相邻帧变化。若分析 `frame 103 → frame 104` 得到异常，就把倍率、推定增量和异常备注写在第104帧行。

正常帧的 `运动异常备注` 留空。异常帧使用简洁、可复核的文字，例如：

```text
运动跨度约为局部正常值的2倍，推定跨越2个原始帧间隔
```

无法可靠评价时不要写“异常”，在普通 `备注` 中写明原因。

数学局部极大但突出度低于本视频门槛时，`运动异常备注`留空，在普通`备注`写明前值、本值、后值、突出度和“不判异常”的原因。目标交接复测后替换代表目标时，在`备注`写明替代目标和复测原因，不保留已确认失真的倍率作为最终代表值。

## 修正算法

对同一OSD秒内的行按帧序号排序。该秒第一帧的修正序号为1。其后：

```text
修正后OSD秒间帧序号_i
= 修正后OSD秒间帧序号_(i-1) + 推定帧间隔增量_i
```

例如：

| 原始序号 | 推定增量 | 修正序号 | 异常备注 |
|---:|---:|---:|---|
| 1 | 1 | 1 | |
| 2 | 1 | 2 | |
| 3 | 1 | 3 | |
| 4 | 2 | 5 | 运动跨度约为局部正常值的2倍，推定跨越2个原始帧间隔 |
| 5 | 1 | 6 | |

OSD秒变化时重新从1累计。原始 `OSD秒间帧序号` 永远不改。

## 质量与缺失值

- `推定帧间隔增量` 正常为1；只有质量合格且完成替代解释复核后才提高。
- `运动不连续倍率` 保存未平滑的相邻帧测量倍率。
- `采用目标` 标明车辆、参照物或ROI编号。
- `有效特征点数` 和 `正反向误差_px` 在采用LK方法时填写；其他方法可留空，并在备注中说明。
- 不可评价帧不插值、不用平滑值覆盖原始结果。
- 在`备注`中保留代表目标的原始投影位移、局部基线、峰值突出度、PTS解释类别和必要的多目标一致性结果；不得只留下最终“异常/正常”标签。
- PTS解释类别至少区分：`运动峰+PTS延长`、`运动峰+PTS未延长`、`仅PTS延长`、`两者均无异常`。PTS类别不改变原始`相邻PTS差_s`。
- 局部区间首帧不是全片首帧时，`相邻PTS差_s`和`相邻DTS差_s`仍应引用全片上一显示帧，不得因截取边界留空。OSD秒从区间前开始时，使用前置缓冲帧确认秒起点并补齐原始秒间序号；确实无法确认时才按边界不完整规则留空。
