# 运动异常判定与PTS解释

## 判定顺序

先判断测量能否使用，再判断曲线形态，最后解释PTS。不要颠倒顺序。

1. **身份与质量**：目标身份连续，ROI未混入邻车或静态背景，有效点、正反向误差和方向一致性达到本视频门槛。
2. **代表目标选择**：每个目标独立计算；目标交接处用重叠帧对比较无量纲倍率。质量最好的目标才写入CSV代表字段。
3. **局部形态**：计算局部基线、倍率和峰值突出度，结合正常段噪声决定候选。
4. **周期一致性**：检查候选是否集中在稳定相位。预期峰突然变谷时优先复测，不把谷值直接当成真实运动骤减。
5. **替代解释**：最后比较PTS、遮挡、透视、真实加减速、反光和全局画面变化。

## 峰值与突出度

严格双侧局部极大可写为：

```text
倍率_i > 倍率_(i-1) 且 倍率_i >= 倍率_(i+1)
```

但这只说明数学形态，不足以判异常。建议同时计算：

```text
峰值突出度_i = 倍率_i - max(倍率_(i-1), 倍率_(i+1))
```

突出度门槛按本视频正常段的局部波动、目标像素面积、特征点质量和人工复核结果校准。可参考正常段突出度分布的高分位数或稳健噪声尺度，不得把某一案件中的固定数值写成通用标准。

- 严格局部极大且突出度合格：进入运动异常候选。
- 严格局部极大但突出度不足：`运动异常备注`留空，在普通`备注`记录“微小局部起伏，已复核不判异常”。
- 倍率很高但目标质量恶化：先标记不可评价或换目标复测，不得仅凭数值判异常。
- 用户明确指定peak规则时仍需澄清“peak”是具有足够突出度的视觉峰，除非用户明确要求连微小数学极值也计入。

## 目标交接与反向谷值

稳定周期中出现以下形态时启动强制复测：

- 预期上峰在目标交接处变成明显下谷；
- 前后帧倍率正常，而单帧突然接近零后立即反弹；
- 代表目标变化与异常位置重合；
- 特征点落在背景、邻车或遮挡边缘。

复测优先级：延长上一目标轨迹 → 使用同画面更大且连续可见的替代车辆 → 调整紧致ROI/掩膜 → 人工边界或轮廓测量。复测后用新结果替换失真代表值，并在`备注`说明。

## 图像运动与PTS证据矩阵

| 图像运动 | PTS | 解释口径 |
|---|---|---|
| 显著峰 | 同步延长 | 运动跨度与长展示间隔相符；仍不能单独证明删帧 |
| 显著峰 | 未延长或缩短 | 长展示间隔不能解释该峰，保留内容更新节奏异常候选 |
| 无显著峰 | 延长 | 记录时序节奏异常，不把它写成运动异常 |
| 无显著峰 | 正常 | 无本项异常证据 |

PTS只描述成品帧展示时刻。不得要求“PTS也异常”才允许写图像运动候选，也不得用均匀PTS证明内容等间隔采样。

## PTS专项分析

当PTS变化异常或疑似周期化时：

1. 使用全片显示顺序检查PTS/DTS是否单调、重复、倒退或缺失。
2. 统计相邻PTS差的均值、中位数、范围、分位数及相对标称间隔的长短分布。
3. 按疑似周期相位分组，例如到达帧号 `mod k`；同时检查不同时间窗口中最大相位是否稳定。
4. 比较单帧间隔变异与连续 `k` 帧总时长变异。若后者显著更小，说明抖动主要在组内重新分配。
5. 计算自相关或频谱确认周期，并检查累计PTS相对平均等间隔的残差是否长期漂移。
6. 对比图像运动倍率与PTS差的相关性，但不要把相关性当因果或删帧证明。
7. `r_frame_rate`、`avg_frame_rate`和时间戳实测值不一致时并列报告；明显异常的`r_frame_rate`不能当作真实采样率。
